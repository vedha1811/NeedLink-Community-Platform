
# NeedLink – Community Help Exchange Platform

NeedLink is a Flask-based hyperlocal community support platform
that enables users to post requests, provide assistance,
communicate with helpers, and send SOS emergency alerts.

## Features
- User Authentication
- OTP Verification
- Need Posting
- Chat System
- Notifications
- NGO Integration
- SOS Emergency Alerts
- Pickup & Drop Assistance
- Admin Dashboard

## Technologies Used
- Flask
- Firebase Firestore
- HTML/CSS/JavaScript
- Leaflet.js
- SMTP Email Service

## Agile Methodology
Project developed using Agile Scrum with 4 sprint iterations.
